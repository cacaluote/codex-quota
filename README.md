# Codex Quota

Codex Quota 是 Windows 桌面上的 Codex 额度悬浮窗。它显示剩余额度、重置时间，以及本机 Codex 会话的 Token 用量。单击悬浮球可展开详情。

## 安装与启动

需要 Windows 10/11，以及已安装并登录的 Codex CLI。本机有 Codex 会话日志时，才能统计本机 Token 用量。可以先在 PowerShell 中运行 `codex --version` 检查 CLI 是否可用。

目前可从源码构建。准备 Rust stable 和 Windows MSVC 构建工具后，在项目目录运行：

~~~powershell
cargo build --release
~~~

生成的程序是 `target\release\codex-quota.exe`。运行后，悬浮球和系统托盘图标会出现。

## 日常使用

| 操作 | 效果 |
| --- | --- |
| 单击悬浮球 | 展开或收起额度面板 |
| 拖动悬浮球 | 移到合适位置；松开后会靠向屏幕边缘 |
| 右键单击托盘图标 | 打开操作与设置菜单 |
| 立即刷新 | 更新额度，并尝试更新模型价格 |
| 面板截图 | 将完整面板复制到剪贴板，也可在资源管理器中粘贴为 PNG 文件 |

托盘菜单可以切换刷新间隔（1、2、5、10、30 分钟）、Token 显示单位（万/亿或 K/M/B）和颜色风格。**设置**子菜单包含始终置顶、开机启动、面板常驻、重置倒计时和缓存命中率等开关。

**跟随 Codex** 默认关闭。开启后，只在 Codex Windows 应用或 CLI 运行时显示悬浮球；此时不能手动显示或隐藏悬浮球。

## 读懂面板

悬浮球通常显示短期额度的剩余百分比。任何一个有效额度窗口耗尽时显示 `0`；没有可用的最新额度时显示 `--`。低于 50% 会变为警告色，低于 20% 会变为紧张色。展开面板可分别查看各额度窗口。

| 面板内容 | 含义 |
| --- | --- |
| 5h、周或月额度 | 各窗口的剩余百分比和重置时间；倒计时可在设置中关闭 |
| 今日使用、本周／本月使用 | 本机在对应时段内的套餐内 Token 用量，以及 API 牌价等价金额 |
| 使用量后的百分比 | 输入 Token 的缓存命中率，例如 `1.2亿 · 98.1%`；可在设置中关闭 |
| 今日超额、本周／本月超额 | 触顶后的本机 Token 用量和账户 credits 实扣折算金额；没有超额时隐藏 |
| 本周／本月估值 | 按当前用量与额度进度推算的本期满额 Token 数及 API 等价金额，仅供参考 |
| 更新时间 | 最近一份额度快照的时间；过期时会提示“已过期” |

“本周／本月”跟随账号的长期额度窗口。缓存命中率只计算套餐内输入 Token，不包含输出或超额用量；没有可计算的输入时不显示百分比。

## 数据来源与限制

额度和重置时间来自本地 Codex 会话记录；需要更新时，程序会临时调用已登录的 Codex CLI 读取账户额度。本机没有新活动时，读数可能停留在上次快照，面板中的更新时间可帮助判断。快照过期或读取失败时，额度可能显示 `--`；`0` 表示已确认耗尽。

Token 用量来自本机保留的官方 OpenAI Codex 会话日志，**不是账户的完整用量**。其他设备、临时会话和已删除的日志不会计入；同一天切换多个账号时，本地日志也可能混在一起。因此本机 Token 数可能与账户额度进度对不上。

绿色美元金额是按模型 API 牌价换算的**等价价值**，不是订阅费用或实际账单。价格来自 models.dev；尚未取得价格表时金额显示 `--`，新模型缺价时金额可能偏低。“估值”还会根据当前额度进度放大本机用量，误差可能更大。

超额行中的美元来自账户 credits 余额变化，可能包含其他设备的消耗；它与旁边的本机超额 Token 数口径不同。

## 通知

托盘菜单的**通知**子菜单可分别开关两类提醒，默认开启：

- **额度重置**：额度窗口重置并恢复可用时提醒。
- **余额使用**：本周期首次观察到使用 credits 时提醒。

单击通知可展开面板。程序未运行、跟随 Codex 模式下已收起，或 Windows 抑制通知时，提醒可能不会出现；程序不会补发错过的提醒。

## 设置与排查

设置、缓存和日志位于 `%LOCALAPPDATA%\codex-quota\`。大部分设置通过托盘菜单修改，无须手动编辑 `config.json`。遇到持续显示 `--` 或刷新失败时，先确认 Codex CLI 已登录、本机留有会话日志，再点击**立即刷新**；仍未恢复可查看 `codex-quota.log`。如果设置过 `CODEX_HOME`，还应检查该目录下是否有 `sessions`。

## 隐私

程序从本机会话日志中提取用量和额度相关元数据，不保存提示词、回复或工具输出。本地数据不会上传；程序自身的网络请求用于从 [models.dev](https://models.dev/) 获取模型价格。读取账户额度时会临时启动 Codex CLI，完成后退出。
